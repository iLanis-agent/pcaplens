PcapLens

A packet-capture inspector that runs entirely in your browser. Drop a .pcap file, get a packet list, full layer decode, and verified IPv4 header checksums. Nothing is uploaded anywhere.

Open PcapLens

What it decodes

  • Classic pcap container: little/big endian, microsecond and nanosecond magics, truncated-file warnings
  • Ethernet (incl. 802.1Q VLAN tags), IPv4 (with header-checksum verification), IPv6 (RFC 5952 address compression)
  • TCP (ports, flags, seq/ack, window, checksum), UDP, ICMP, ICMPv6 echo, ARP
  • DNS: question names with compression pointers, first answer (A records) with TTL

Why trust it

The JavaScript engine is checked field-by-field against scapy in tests/run_tests.js: 500 assertions over a six-file corpus covering TCP, UDP/DNS, ICMP, ARP, IPv6, a nanosecond-resolution file, and a truncated capture. IPv4 header checksums are verified independently in the oracle.

Limits

Only LINKTYPE_ETHERNET files are decoded (other link types load with a warning). pcapng is not supported. TCP/UDP checksums are displayed but not verified (they need a pseudo-header; IPv4 header checksums are verified). DNS answers beyond the first record are not shown.
